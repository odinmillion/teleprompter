# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Телесуфлер «Суфлер» для iPhone, который кладут в зеркальный ригель (beam-splitter). Основной сценарий: пользователь вставляет текст, включает зеркало, кладёт телефон в суфлер и читает через стекло, стоя перед камерой. Всё остальное — второстепенно.

## Команды

Сборки, линтера и тестов нет и заводить их не нужно — никакого `package.json`. Проверка только ручная, по чек-листу ниже.

- `open index.html` — открыть локально; страница работает из файла без сервера.
- `./deploy.sh` — первый деплой на GitHub Pages, см. раздел «Деплой». Дальше — обычный `git push`.

## Архитектура

- **Один файл `index.html`**: разметка, CSS и JS внутри. Никаких сборщиков, npm, фреймворков и внешних ресурсов (шрифтов, CDN). Это сознательное решение — страница должна открываться с GitHub Pages и из локального файла без сети. Не раскладывать на отдельные файлы без явной просьбы.
- Два экрана: `#editor` (textarea + настройки) и `#prompter` (чёрный полноэкранный суфлер). Переключение — `enterPrompter()` / `exitPrompter()`; в режиме суфлера на `<html>` стоит `data-mode="prompt"`.
- **Зеркало** — CSS `transform` на `.stage` (классы `.mh`, `.mv`, обе сразу → `scale(-1,-1)`). Линия чтения `#guideLine` и `#readout` лежат внутри `.stage` и зеркалятся вместе с текстом; `#readout` — дубль тоста над линией чтения, `toast()` включает его только при включённом зеркале, чтобы скорость и шрифт читались через стекло. Панель кнопок `.bar`, тост и прогресс-бар лежат **вне** `.stage` и не зеркалятся — так и задумано, их читают, глядя на телефон напрямую. Панель прижата к низу, над прогресс-баром; ряды в `column-reverse`, чтобы основной (← ⟲ Старт) был ближе к большому пальцу. Тост стоит на 18 % высоты, не по центру: центр занят цифрами отсчёта.
- **Прокрутка** — `requestAnimationFrame`, позиция `pos` в пикселях, `track.style.transform = translate3d(0,-pos,0)`. Скорость `S.speed` — пиксели в секунду. `layout()` задаёт `padding-top` трека = линия чтения (33% высоты экрана, `GUIDE_RATIO`) и `padding-bottom` так, чтобы последняя строка доезжала до линии; `maxPos = track.offsetHeight - stage.clientHeight`. `tick()` ограничивает `dt` 0,1 с, чтобы после возврата из фона текст не прыгал. На `maxPos` — `pause()` и тост «Конец текста»; `play()` с конца начинает с нуля.
- **Состояние** — объект `S` (speed, font, margin, color, align, mirrorH, mirrorV, guide, countdown, markup) и строка `text`. Хранятся в `localStorage` под ключами `tp.settings` (JSON) и `tp.text`. Если ключа `tp.text` нет вовсе (первый запуск) — подставляется `DEMO`, сценарий со всеми знаками разметки; пустая строка после «Очистить» так и остаётся пустой. У пустого поля вместо «Очистить» показывается «Пример» (`updateWords()` переключает кнопки), он возвращает `DEMO`. Загрузчик берёт из хранилища только те ключи, чей `typeof` совпадает с `DEFAULTS`, остальное молча сбрасывает в дефолт: новой настройке миграция не нужна, а смена типа существующей обнулит её у пользователя. Ключи и формат менять нельзя — у пользователя уже сохранены данные.
- **Добавить настройку** — шесть мест: контрол в `.settings`, запись в `inputs`, `DEFAULTS`, `syncInputs()`, `applySettings()` и привязка события (`bindRange` для слайдеров, циклы по `change` для селектов и переключателей).
- **Дубли, которые меняются вместе**: диапазоны скорости (5–150) и шрифта (20–120, шаг 2) живут в `min`/`max`/`step` слайдеров, в клампах `setSpeed()` / `setFont()` и в README; раскладка клавиш — в обработчике `keydown`, в абзаце `.hint` редактора и в README.
- **Разметка** (`S.markup`, по умолчанию включена) — `renderText()` при входе в суфлер строит DOM по строкам: `div.ln` на строку (пустая — с `<br>`), `.h` для `# `, `.stop` для `---`, `span.who` для `ИМЯ:` заглавными, инлайн `span.em` для `**…**` и `span.note` для `[…]`, строки с `//` пропускаются. Только `createElement`/`textContent`, никакого `innerHTML`. При выключенной разметке — `textContent = text`, как раньше. `layout()` собирает `stops` и `heads` как `offsetTop − guideY` (единицы `pos`); `tick()` перед шагом проверяет `nextMark(stops, pos)` и на стоп-метке делает `pause()` с тостом; PageUp/PageDown при наличии заголовков прыгают по `heads`, иначе на полэкрана. Счётчик слов считает `plainText()` без служебных знаков. Синтаксис описан в трёх местах: второй абзац `.hint` в редакторе (каждый знак с новой строки, под ним кнопка `.secondary`), константа `PROMPT` (кнопка «Скопировать промпт для ИИ») и README — менять вместе.
- **Отсчёт 3-2-1** (`S.countdown`, по умолчанию включён) — `play()` вместо старта запускает `startCountdown()`: цепочка `setTimeout` по секунде, цифра в `#cd` внутри `.stage` (зеркалится, чтобы читалась через стекло), затем `play(true)`. Пока идёт отсчёт, кнопка — «Отмена», `pause()` его гасит; любое касание сцены отменяет и тапом не считается (`pd.caught`). Сброс позиции с конца на начало делается до отсчёта, чтобы во время него был виден старт текста.
- **Wake Lock** — `navigator.wakeLock.request('screen')` при входе в суфлер и при старте; повторный запрос на `visibilitychange`; освобождение при выходе. Тост «Экран не погаснет» — при каждом успешном захвате, при отказе (например, режим энергосбережения) — «Экран может погаснуть…». Если API нет — тост с советом отключить автоблокировку.
- **Жесты** на `.stage` через Pointer Events: тап (<8 px, <500 мс) — старт/пауза; вертикальный драг во время прокрутки — скорость (0,25 ед./px), на паузе — ручная перемотка. При `mirrorV` знак `dy` инвертируется, чтобы жест был интуитивным относительно того, что видно в стекле. Во время драга скорость ставится «тихо» (`setSpeed(v, true)`, без записи) и сохраняется один раз на `pointerup`. На паузе после отпускания пальца — инерция: скорость по последним 100 мс жеста, затухание `exp(-2·dt)` как у UIScrollView, стоп у края или ниже 30 px/с. Тап по летящему тексту его останавливает и тапом не считается (`pd.caught`); `play()`, `restart()`, PageUp/PageDown и выход гасят инерцию через `stopFling()`.
- **Клавиатура** — обработчик `keydown` только в режиме суфлера; дублирует латинские клавиши русскими (M/ь, V/м, R/к, F/а) на случай русской раскладки пульта. Полная карта клавиш — в README.
- **Полный экран** — кнопка ⤢ (`#fsBtn`) и клавиша F вызывают Fullscreen API на `#prompter` (с `webkit`-префиксом для старых iPad). Доступность — по `document.fullscreenEnabled`, а не по наличию метода: на iPhone метод есть, но для элементов не работает. Без API кнопка показывает подсказку про экран «Домой», а в режиме ярлыка (`navigator.standalone` / `display-mode: standalone`) прячется. `exitPrompter()` выходит из полного экрана, иначе редактор остался бы за пределами fullscreen-элемента.
- **Тема** редактора — CSS-переменные на `:root` по `prefers-color-scheme`. Атрибут `data-theme="light|dark"` на `<html>` переопределяет системную тему, но из JS сейчас не выставляется.

## Ограничения iOS Safari, которые нельзя ломать

- `<meta name="viewport" ... viewport-fit=cover>`, отступы `env(safe-area-inset-*)` на `:root`, на `.bar` / `.progress` и боковые на треке (inline `calc()` в `applySettings()`) — иначе контент уедет под чёлку и индикатор «Домой», а в ландшафте — под чёлку сбоку.
- Fullscreen API на iPhone не работает для элементов страницы, только для видео (проверено по caniuse и форуму Apple, ноябрь 2026). Полный экран на iPhone — только «На экран Домой».
- Защита от случайного зума: `touch-action: manipulation` на `html`/`body` (двойной тап по «+»/«−» иначе приближает страницу), шрифт `select` не меньше 16 px (иначе iOS приближает при фокусе), `gesturestart`/`gesturechange` с `preventDefault` в режиме суфлера (щипок). `user-scalable=no` не помогает — Safari его игнорирует.
- Высота экрана — `height: 100%` на `html`/`body`, не `100vh`; для textarea `40dvh`.
- `.stage`: `touch-action: none`, `user-select: none`, `-webkit-touch-callout: none`, у `body` `overscroll-behavior: none` — без этого iOS перехватывает свайпы, показывает лупу и «резинит» страницу.
- `layout()` при входе в суфлер вызывается через `requestAnimationFrame` (элемент только что был `hidden` и ещё без размеров), а на `orientationchange` — через `setTimeout(…, 150)`: сразу после поворота iOS отдаёт старые размеры.
- Шрифт полей ввода (`textarea`, `select`) не меньше 16 px, иначе iOS приближает страницу при фокусе. Задавать отдельными свойствами: шорткат вида `font: 17px/1.45 inherit` невалиден (CSS-wide keyword внутри шортката), объявление отбрасывается, и поле падает на браузерный шрифт 13 px.
- Фон суфлера — чистый `#000`, не «почти чёрный»: через стекло любой серый засвечивает кадр.
- Чекбоксы с атрибутом `switch` — в Safari 17.4+ рендерятся как iOS-переключатели, в остальных браузерах деградируют в обычные чекбоксы. Так и оставить.
- `apple-mobile-web-app-capable` + `manifest.webmanifest` + `apple-touch-icon.png` — для режима «На экран Домой». Иконки — PNG, SVG для apple-touch-icon iOS не понимает.

## Стиль

- Интерфейс по-русски, типографские кавычки «…», тире —.
- Редактор — спокойный утилитарный вид, тема следует системной (светлая/тёмная) через CSS-переменные на `:root`. Акцент — янтарный `#B9840A` / `#F0B43C` (цвет текста на классических суфлерах). Не добавлять декор, карточки, тени, анимации появления.
- Экран суфлера — только текст, линия чтения и тонкий прогресс-бар.

## Деплой

GitHub Pages из ветки `main`, корень репозитория. `./deploy.sh` (нужен авторизованный `gh`) создаёт публичный репозиторий и включает Pages; если `.git` ещё нет, скрипт сам делает `git init -b main` и первый коммит. Дальше обычный `git push`. `.nojekyll` обязателен.

## Чек-лист после изменений

1. Открыть на iPhone в Safari: вставить длинный текст (несколько экранов), «Начать» → тост «Экран не погаснет».
2. Тап по тексту — старт; панель прячется через 2,5 с; тап — пауза, панель возвращается.
3. Свайп во время прокрутки меняет скорость, на паузе — перематывает.
4. Включить ↔, ↕ и оба сразу — текст и линия чтения отражаются, панель кнопок нет.
5. Перезагрузить страницу — текст и настройки на месте.
6. Прокрутить до конца — остановка, тост «Конец текста»; повторный старт — с начала.
7. Повернуть телефон — текст перелэйаутился, позиция не улетела.
8. Добавить на экран «Домой» — открывается без адресной строки, иконка на месте.
9. Быстро нажать «+» несколько раз и щипнуть по тексту — масштаб страницы не меняется. В ландшафте кнопки и текст не под чёлкой.
10. С включённым зеркалом свайпнуть скорость — над линией чтения появляется зеркальная плашка со значением.
11. На паузе резко свайпнуть — текст едет по инерции и плавно останавливается; тап по летящему тексту останавливает его, не запуская прокрутку.
12. Тап по полю ввода в редакторе — страница не приближается.
13. С включённым отсчётом тап по тексту — крупные 3, 2, 1 поверх текста, потом прокрутка; тап во время отсчёта его отменяет, не запуская прокрутку. С выключенным — старт сразу.
14. Вставить текст с `**`, `# `, `[…]`, `---`, `ИМЯ:` и `//` — в суфлере акцент и заголовок янтарные, ремарка серая и мелкая, стоп-метка пунктиром и прокрутка на ней останавливается, скрытой строки нет; PageDown прыгает к следующему заголовку. Выключить разметку — текст как набран.
15. В приватной вкладке (чистое хранилище) в поле лежит пример с разметкой; «Очистить» → поле пустое и после перезагрузки, рядом кнопка «Пример», которая возвращает демо.
16. «Скопировать промпт для ИИ» в справке редактора — кнопка на полторы секунды становится «Скопировано», в буфере промпт с правилами.
